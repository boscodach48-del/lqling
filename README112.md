# 群里刷广告那晚，我连删的按钮都找不到：网页版管群的 7 项管理员权限、3 条操作路径与踩坑记录

凌晨一点，一个做社区团购的群友给我发截图：三百多人的客户群里，进来两个号，一分钟刷了四十条"低价代充"。他人在外面，用手机连着热点，在浏览器里开了网页版，想先把广告删了。结果他对着屏幕戳了十分钟——鼠标移到消息上，右键，只有"回复""转发""复制"，没有"删除"。

我让他把账号右下角的身份报给我，一句话就结案了：**他根本不是这个群的管理员，是半个月前点了个邀请链接进来的普通成员。** 删不了不是浏览器的问题，是权限压根没给。

这篇就把网页版管群这件事拆开讲：谁有什么权、删人封人从哪进、成员列表那几个抽屉各管什么。界面术语的中英对照和面板截图，我一般对着 👉 [Telegram网页版中文说明](https://tlgrgm-web.com) 核一遍，省得在不同版本来回猜。

## **一、先认身份，再找按钮**

网页版管群最消耗时间的不是操作，是"我以为我有权限"。三条身份线要先分清：

- **群主（创建者）**：全部权限，也是唯一能解散群、转让群、删管理员的人。
- **管理员**：权限是逐项勾选的，勾了"删除消息"才能删别人的话，没勾就只能管自己。
- **普通成员**：右键菜单里天生没有"删除"这一项。找不到入口，多半是这一层。

对着下面这张矩阵看，比在界面上乱点快得多。

| 操作 | 群主 | 全权管理员 | 限权管理员 | 普通成员 |
| --- | --- | --- | --- | --- |
| 删自己发的消息 | 可 | 可 | 可 | 可 |
| 删别人发的消息 | 可 | 需"删除消息"权限 | 通常无 | 入口不存在 |
| 移除成员 | 可 | 需"封禁用户"权限 | 无 | 无 |
| 封禁并拉黑 | 可 | 需"封禁用户"权限 | 无 | 无 |
| 改群名、群头像、群简介 | 可 | 需"更改群信息"权限 | 无 | 无 |
| 置顶消息 | 可 | 需"置顶消息"权限 | 无 | 无 |
| 拉人、生成邀请链接 | 可 | 需"邀请用户"权限 | 视勾选 | 视群设置 |
| 加/撤管理员 | 可 | 需"添加新管理员"权限 | 无 | 无 |
| 解散群、转让群 | 仅群主 | 无 | 无 | 无 |

频道是另一套逻辑：订阅者不算成员，所以权限列表里根本没有"封禁用户"，只有发布、编辑、删除、管理视频聊天这几项。把频道当群管，第一步就会卡住。

## **二、路径一：从消息上直接动手**

临时清屏最快，不用进设置。

1. 鼠标停在要处理的那条消息上，右键（触控板两指单击也行）。
2. 选"删除"，弹窗里有一行复选框，写着**为所有成员删除**。
3. 勾上再确认。不勾的话，只是你这边看不见了，群里其他人照样能读到——这一条我见过太多人翻车，删完还在群里被截图打脸。
4. 要顺手处理人，就在同一条消息上右键 → 发送者头像 → 资料卡右上角"⋮" → 封禁用户。

如果这步右键里只有"回复/转发/复制/固定"，不用怀疑浏览器：回第一节看身份，或者让群主进"管理员"页签给你补勾"删除消息"。

## **三、路径二：群信息抽屉，五块内容**

点顶部群名，右侧滑出信息抽屉，最上面那支铅笔就是管理入口。抽屉里从上到下是：**类型、权限、管理员、成员、邀请链接**（英文界面是 Type / Permissions / Administrators / Members / Invite Links）。近期的网页版把"已移除用户"并进了成员页签的筛选里。

几个真正常用的开关，位置都在这里：

- **权限 → 发送消息**：关掉之后群变成"只有管理员能发言"的公告模式。普通成员那边输入框会变灰，提示大意是"只有管理员可以在此群发送消息"（不同版本译法不一样，别按字面去搜）。
- **权限 → 慢速模式**：刷屏那半小时开 30 秒很管用，一个人一分钟只能说两句。日常记得关，不然成员会追着问"为什么我发不出第二条"——那提示就是慢速模式在拦。
- **管理员 → 保持匿名**：勾上之后，你的操作以群名义展示，发言署名是群名而不是你的昵称。好处是不被私聊骚扰，代价是回复问题时对方不知道在跟谁说话，客服类群慎用。

## **四、路径三：成员管理那三个抽屉**

真正的日常工作量在成员页签，三条线要分清：

**加入请求。** 开了"需管理员批准"的群，成员页签顶部会挂一条"N 个加入请求"。这里只显示数量，点进去才是一条条头像，可以逐个批准或拒绝。放着一周不管，新客户就以为这群死了。

**邀请链接。** 网页版能生成默认链接，但**限制使用次数、设置有效期、要求管理员批准**这几项，我这边得回手机端的"群信息 → 邀请链接 → 新建链接"才齐全。做完回网页版，链接会同步过来，直接复制发客户即可。做活动拉人时用一个限 50 次的临时链接，比长期公开链接安全得多。

**移除与封禁的区别。** 这是最容易被忽略的一处：

1. 成员列表点开某人 → "⋮" → **移除**：人立刻不在群里，但旧邀请链接还有效，他自己点一下又回来了。
2. 同一位置选 **封禁用户**：进黑名单，靠链接也回不来，只有管理员手动解封才行。
3. 解封在成员页签的筛选里切到"已封禁"，点头像 → 解除封禁。

所以清广告号一定要走封禁。只移除，等于给对方留了后门。

## **五、找不到入口时，先查这四处**

同一套功能在不同版本里长得不一样，这也是"我明明看到过"的来源。

- **版本差异。** 现在打开网页版默认进 K 版，管理入口是"点群名 → 右抽屉 → 铅笔"。A 版（地址带 `/a`）是右上角"⋮ → 管理群组"，面板是居中弹窗，页签名字也略有出入。老 Z 版已经不再维护，登录会被跳转，缓存里残留的旧页面按钮还藏在二级菜单里，容易误判成功能被砍。
- **窗口宽度。** 窗口窄于一千像素左右，右抽屉会变成整屏覆盖层，返回箭头跑到左上角；抽屉再窄，"权限"这类页签会折叠成图标，只显示齿轮。把窗口拉宽或按 F11 全屏，很多"消失的按钮"就回来了。
- **浏览器缩放。** 之前为了看清中文把页面放到 125%，结果面板底部的"保存"被挤出可视区。`Ctrl + 0` 重置回 100% 立刻正常。少一个零也能救半小时。
- **面板没刷新。** 刚被加为管理员时，右抽屉可能还是旧状态，刷新一次页面权限就到位了。别急着重登，重登要重新扫码。

管理员设置这块，站点上有一节讲[群组与频道的分工](https://tlgrgm-web.com)，和这里的权限项是能对上的，遇到译名对不上时翻一下比较省事。

## **六、给三类群配三套权限**

同样是"管群"，配置思路完全不同，我按自己维护的几个群列一下：

| 群类型 | 权限怎么设 | 慢速模式 | 邀请方式 |
| --- | --- | --- | --- |
| 客户服务群 | 全员可发言，只给两名管理员"删除消息+封禁" | 关闭 | 一次性链接，用完即废 |
| 大群/社区群 | 全员可发言，配两名管理员专门盯"删除消息+封禁" | 高峰开 30 秒 | 需管理员批准 |
| 内部通知群 | 关掉"发送消息"，只留管理员发言 | 不需要 | 不加外部成员 |

第三类最省心：权限一关，群里只剩结论，没人刷"收到"。代价是讨论要另开一个群，别在一个群里既要安静又要热闹。

## **群主的活一半在设置里**

那晚的广告是群主上线封的号，前后不到两分钟。差别不在手艺，在他手里有那两项权限，而他朋友手里没有。

网页版管群的门槛就这么点：**认清身份 → 认准三条路径（消息右键、群信息抽屉、成员页签）→ 把"移除"和"封禁"分开用**。剩下的都是熟练度。权限矩阵存一份在笔记里，下次群里再刷屏，你不用先花十分钟找按钮。

具体到每个页签的按钮位置和中文叫法，可以直接照着 [tlgrgm-web.com](https://tlgrgm-web.com) 的图文步骤走一遍，配合自己群里的实际界面核对，比记名词管用。
