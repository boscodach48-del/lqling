# 老号用了一周被踢下线：会话、邮箱、设备、找回通道四项检查怎么排，判断原主人有没有摸回来（附抢回顺序）

第 8 天早上 7 点 40，手机弹出一条 Telegram 通知，大意是「新设备登录」，跟着一个我没去过的地名。还没点开，界面自己跳回手机号输入页；桌上那台客户端更直接，红色一行 `AUTH_KEY_UNREGISTERED`，退回登录页。前一晚我还在那个号里给频道排下周推送，一周的客户对话和三十几个群全在那一个界面上。

当时的判断很干脆：原主人把号拿回去了。

复盘后，这个判断只对了一半。手上和客户的十几个 **TG老号** 按同一套流程过了一遍，真被原主人摸回去的只有 4 个；剩下的是 IP 跳变强制下线、客服换号后旧会话没同步、买家自己清了会话却以为被挤掉。处置方向完全相反——前一种要抢，后两种越抢越糟。

## **一、先分清「被踢」的三种来源，别一上来就抢**

同一个症状，三种成因，判据只有时间线和残留痕迹。

| 症状 | 更可能是 | 判据 |
| --- | --- | --- |
| 全部设备同时掉线，重登直接收短信/邮件验证码，没有密码提示 | 风控强制下线 | 掉线前后你换过节点或 IP；重登流程和新机首登一模一样 |
| 只有一台掉线，其余还在，`设备` 列表多出一条陌生会话 | 原主人登录 | 陌生会话有独立 IP 与活跃时间；你的设备被单独终止 |
| 掉线但 `设备` 列表干干净净，两步验证密码仍是你设的那个 | 自己或客服动了会话 | 没有新增会话；时间点对得上你清会话或售后换号 |

第一种最容易被误判成被盗。我在机场节点上一天切三个地区，第二天早上被全线踢出，也收到「新设备登录」通知——那是 Telegram 对异常 IP 的告警，不是原主人在另一台手机上点了登录。前者重登就回，后者会卡在两步验证密码上。

## **二、四项检查：会话、邮箱、设备、找回通道**

这四项不是并列关系，是一枚钥匙的四段。老号交付时手机号几乎都不在你手上——68 元那档交的是号码加取码通道，短信始终落到原主人或卡商那边。这条收码的路从第一天起就不由你控制，你能守的只有另外四条。

**① 会话：设置 → 隐私与安全 → 设备**

每一行带设备型号、地区、最近活跃时间，点进去有单独的「终止会话」。右上角「终止所有其他会话」是一键兜底，检查阶段别按。要看的是**条目数量和你用过的终端是否对得上**：我一手机一桌面，出现第三行就该警觉。真判据是活跃时间落在你睡觉的时段、IP 又不在你常用地区。

**② 设备：别信设备名，信 IP 和作息**

型号是客户端自己上报的字符串，第三方客户端能写成任何东西，挂一行「iPhone 15 Pro」不代表真有台 iPhone 在登。我只比 IP 归属地和最近活跃时间能不能对上你的作息。

**③ 邮箱：设置 → 隐私与安全 → 登录邮箱（Login email）**

四条线里最隐蔽的一条。绑上之后，新设备的登录验证码会同时发到这个邮箱，等于把收码从原主人的短信挪到你能控制的地方。这栏里躺着一个你不认识的地址，说明对方给自己留了门：等你掉线时用邮箱收码登一次就够了。

见过最典型的翻车：买家把两步验证密码换成了自己的，登录邮箱那栏没动，还是交付时预填的。三周后号被登走，他还在群里问「密码都改了怎么还能进」。密码只挡登录，邮箱能改密码。

**④ 找回通道：手机号、两步验证密码、登录确认弹窗**

三样一起看。手机号在谁手上你已经知道。两步验证密码要确认「是不是你设的」——进「设置 → 隐私与安全 → 两步验证」点「更改密码」，若它要你先输一个你没设过的旧密码，这密码就是别人的。第三种是登录确认弹窗：你有设备在线时，别人用手机号登录会先推一条确认，能直接拒掉。常在线设备就是门铃。

四项压成一张表，逐项打分：

| 检查项 | 看哪里 | 正常的样子 | 已被接管的样子 |
| --- | --- | --- | --- |
| 会话 | 隐私与安全 → 设备 | 条目数等于终端数，活跃时间在你的作息内 | 多出陌生条目，凌晨活跃，IP 跨地区 |
| 设备 | 同上，逐条点开 | 型号不重要，IP 与时间对得上 | 型号眼熟但 IP 陌生，或常年挂着一台你叫不出名的终端 |
| 邮箱 | 隐私与安全 → 登录邮箱 | 是你自己的邮箱，能收到测试验证码 | 空着却从没设过，或显示陌生地址 |
| 找回通道 | 两步验证 + 在线设备弹窗 | 密码是你设的，在线设备能收到登录请求 | 点「更改密码」要求输入未知旧密码 |

四项全绿，号是你的；黄一项当晚处理；红两项按下一节顺序抢。

## **三、检查要从邮箱开始，抢回要从密码开始**

对方动手的顺序和我检查的顺序正好相反。拿走一个号最短的路径：先改登录邮箱，把收码权挪走；再改两步验证密码，把你锁在门外。你打开 App 只看到登录页。

所以检查倒着走，从最上游的邮箱查起；抢回顺着走，从你手上还握着的东西开始。顺序错了会丢窗口：先去改昵称、先发公告，等于告诉对方你发现了，他立刻清会话。

## **四、抢回顺序：七步，别跳**

前提是还有一台设备在线，或者还能进去。进去后按次序动，中间不重登、不改资料、不发消息。

1. **换回自己的线路**。别在公共节点上操作，避免抢回时再吃一次风控。
2. **改两步验证密码**。设置 → 隐私与安全 → 两步验证 → 更改密码，换成没用过的新密码。他不知道新密码，拿手机号也进不来。
3. **改登录邮箱**。换成自己随时能收信的地址，改完点一次「重发验证码」确认能收到。若提示要先验证当前邮箱而你收不到，说明邮箱已被换走，跳到第 7 步。
4. **清会话**。回设备列表逐条核对，把非你的终端全部终止，再按一次「终止所有其他会话」。清完等十分钟，别马上重登。
5. **撤授权**。同一页往下翻，不认识的已授权网站、第三方客户端、机器人授权全撤；老号这块很脏，前号主常留着几个营销工具。
6. **认清手机号边界**。号码不在你手上，改不了；能做的是让「号码 + 短信」单独失效。
7. **抢不回来就止损**。密码被改、邮箱被换、你也进不去，别反复重登：连续取码会进冷却，一旦出现 `Too many attempts. Please try again later.`，24 小时内没有第二次机会。订单号整理好走售后。

那句报错是「还能不能抢」的分界线：看到它就停手，硬试只会把窗口拖没。

## **六、四条线一次收干净，比出事后再抢省事得多**

现在的习惯是收号当晚花十五分钟做四件事：进「设备」清一遍；进「两步验证」确认密码是自己设的；进「登录邮箱」填自己的地址并测一次收信；隐私设置里关掉手机号可见范围。做完，号才算转到我名下。

那批号里四项全绿的只有一半。另一半要么邮箱是卖家的，要么两步验证的旧密码没人知道。它们当时都能正常用，差别只在于出事那天你有没有第二把钥匙。

号在你手里，从来不是因为钱付过了，而是因为这四条线都在你手上。四条线全绿的那天它才真正属于你；有一条还挂在别人名下，它就只是暂时借给你用。
