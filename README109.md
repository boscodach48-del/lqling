# 夜里被震醒、白天又怕漏消息：一张时段表加三条例外规则，把 Telegram 免打扰、静音和关键词提醒配成一套

上个月有天凌晨三点十七分，手机在床头柜上连着震了五下。我摸黑抓过来看，是一个海外供货群在轮班交接，五条消息没一条跟我有关。第二天我赌气把所有通知开到最大，结果一整个上午被"好的""收到""已转"切了二十几刀，真正需要我回的那条报价，反倒埋在一堆灰字里被我划过去了。

两件事其实是一件事：**免打扰和"怕漏消息"是同一个旋钮的两头**。一个总开关只能二选一，要么吵醒，要么漏掉。真正管用的是把通知拆成几层，按时段给粗细，再留几个能穿透的例外。这套东西我一台一台机器配过之后，才算把这半年睡踏实了。

## 通知我按三层来管，不按"开/关"来管

- **时段层**（全局）：决定一天里哪些小时允许响。桌面客户端的"通知配置文件"就是这个东西。
- **会话层**（静音）：决定哪几个群、哪几个人永远不响，跟时间无关。
- **例外层**（白名单）：决定谁能穿透上面两层。这层的会话数最好控制在三五个，多了等于没设。

有个判断口径，我拿来区分症状，比逐个点开省事：**整晚每隔一会儿就响一次**，是时段层没生效；**只有某一个群整天在响**，是会话层漏了静音；**重要的人发了消息也没动静**，是例外层没把他加进去或者他被单独特意静音过。三种症状对应三个不同位置，别混着改。

菜单名各版本略有出入，中文界面的对照可以看 [中文界面设置方法](https://tlgrkg-web.com)，找"通知和声音"这一项就对了。

## 一张按小时排的时段表

这是我现在实际在用的排法，两套配置文件轮着切：一套叫"夜间低优先"，一套叫"午间免打扰"。

| 时段 | 我要的效果 | 哪一层负责 | 具体动作 |
| --- | --- | --- | --- |
| 00:00–07:00 | 除两个人之外一声不响 | 时段层 + 例外 | "夜间低优先"00:00 起、07:00 止，例外只加两个私聊和一个值班群 |
| 07:00–09:00 | 只响私聊，群全部压住 | 时段层 | 同配置文件延长到 09:00，群里靠文件夹角标扫 |
| 09:00–12:00 | 全部正常响 | 手动切换 | 配置文件临时停用，回默认 |
| 12:00–13:30 | 午休静音，只留电话式提醒 | 时段层 | "午间免打扰"12:00–13:30，例外加直属上级一人 |
| 13:30–19:00 | 该响的响，但别出声 | 会话层 | 大群统一静音，靠未读数字和置顶 |
| 19:00–23:00 | 只响项目群 | 时段层 + 例外 | "夜间低优先"提前到 19:00 启用，例外换成项目群 |
| 23:00–24:00 | 收尾，只留角标 | 会话层 | 网页版标签固定但关掉声音，桌面客户端留着 |

排表的时候有个反直觉的地方：**不要把"静音"当成"不重要"**。静音的会话照样在涨未读数、照样能被搜到，它只是不出声。真正决定"能不能漏"的是你有没有一个每天扫一眼未读的习惯，而不是把每个群都设成响铃。

## 一条例外规则怎么配进去，五步

以桌面客户端为例，这条是要让"夜间低优先"里那两个私聊能穿透静音：

1. **打开 设置 → 通知和声音 → 通知配置文件**，点"新建配置文件"，名字填"夜间低优先"。老版本这里没有"配置文件"入口，只有"例外"，那就只能做单层，第七条会讲。
2. **勾"启用时间"**：工作日 00:00 到 07:00，周末单独再建一条 00:30 到 08:30。别指望一条规则覆盖七天，周末的作息跟工作日差得远。
3. **进"例外"**，选"指定聊天"，只加那两个私聊和一个值班群。列表里加群很容易手滑，加完回头数一遍数量，超过五个就说明你把白名单当成了"我在意的所有群"。
4. **给白名单单独指定提示音**，跟默认音区分开。这一步是整套设置里最值钱的一步——听到"叮"不用起身，听到那个特有的短促音才需要摸手机。
5. **保存后回列表确认状态是"已启用"**，再切到网页版刷新一次，看被静音的会话在网页端是不是也带上了静音图标。配置没同步到网页端，八成是没刷新。

顺手记一个容易点错的坑：单个会话的静音有四档——**1 小时、8 小时、48 小时、关闭**。这里的"关闭"是关闭静音，也就是恢复响铃，不是"永久静音"。我头一次点的时候理解反了，第二天早上被那个群叫醒。

## 关键词提醒：原生没有全局入口，三条替代路径

Telegram 没有"全局关键词告警"这个开关，指望在设置里填几个词就完事，会一直找不到。我试下来，下面三条路径覆盖了绝大多数真实需求。

**路径一：白名单式。** 把"每条都值得看"的会话挑出来，通常不超过八个，单独建成一个文件夹，只给这批开声音。所谓关键词提醒，九成的诉求其实是"这几个会话不能漏"，只是平时被一堆无关的群稀释了。

**路径二：提及式。** 让群里的人改用回复和 @ 来找你，普通消息全部静音。这样一来"关键词"就变成了"@你的名字"，天然精准，代价是需要跟同事约定一次规则。约定了之后群里再吵也跟你无关，@ 一到照样响。

**路径三：自建关键词机器人。** 前两条压不住的时候用这条。写个小机器人挂在群里，收到更新就按关键词表匹配，命中之后往"收藏夹"（Saved Messages）发一条摘要，再把收藏夹加进夜间白名单。这样"关键词"就跑在了时段层和例外层之上，逻辑上不冲突：白天它只是一个安静的备忘，夜里它就是那个能叫醒你的唯一通道。

三条路可以叠。我现在是路径一做底、路径二管群、路径三只管两个采购关键词。

## 网页版只接得住一半

web.telegram.org 的设置里，"通知"那一页只有三行：桌面通知开关、声音、消息预览。没有配置文件、没有启用时段、没有例外名单。它继承的是**会话层的静音状态**——你在桌面客户端点过静音的群，刷新网页后照样带静音图标，声音也不响；但时段表在网页端完全不生效，凌晨三点该弹还是弹。

所以网页版适合当"白天的前台"，夜里那套得靠桌面客户端或手机端顶着。最简单的办法是夜里关掉那个标签页——关标签不等于退出登录，手机上照常收消息，只是电脑不再弹。上线入口和登录流程在 [Telegram网页版入口](https://tlgrkg-web.com) 那边有，登完不用管它挂着。

还有一个必须先解的前置问题：如果浏览器那边把通知权限拒了，网页版设置页会显示"通知已被浏览器阻止，请在地址栏的站点设置中允许"。这句出来的时候，改配置文件、加例外全是白费，先去地址栏左边的站点图标里把通知改成"允许"，再刷新页面。

## 配错了的样子，三种对照

| 症状 | 真实原因 | 一处改动 |
| --- | --- | --- |
| 整夜还是每隔十分钟响 | 配置文件建了但没勾"启用"，或时间填成了 07:00–00:00 | 回配置文件列表看状态与起止 |
| 重要的人发消息也不响 | 例外里加了群没加私聊，或那个私聊被单独静音过 | 会话 → 通知 → 关闭静音 |
| 手机响、电脑死活不响 | 网页版标签被浏览器休眠，或站点权限被拒 | 固定标签、查站点权限 |

## 我换机器时的三分钟复刻

这套东西我当成一张配置清单存在备忘录里，换电脑照着点：建配置文件 → 排两套时段 → 加三到五个例外 → 把白名单会话的提示音换掉 → 刷新网页确认同步。三分钟能走完，走完之后就不用再想通知这回事了。

现在凌晨三点那五下震动没了。真有事的两个人发消息照样响，铃音不一样，我摸黑看一眼屏幕就知道要不要起身。白天那些"收到""好的"也照常进来，只是不再出声——它们躺在未读数里，等我手上这一段做完再去扫。整套设置的中文菜单对照都在 [通知与免打扰](https://tlgrkg-web.com) 那一节，版本更新后菜单名对不上时，按"设置 → 通知和声音"这个顺序往下找就行。
