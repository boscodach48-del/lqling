# 语音通话里对方听不到我说话：Safari 摄像头、麦克风、通知三项站点权限的清单与改法

上周三下午跟同事在网页版开语音，接通之后对面连着问了三遍"你那边是不是静音了"。我这边看着一切正常：通话按钮亮着，头像在闪，就是没人听见我。把输入电平条放大看——一条平平的灰线，从头到尾没有起伏。地址栏安静得很，没有提示、没有图标、没有一句解释。

关掉重进、换耳机、拔了再插，全白费。真正的原因藏在 Safari 的一条记录里：这个站点被记成了"麦克风：拒绝"。这个状态一旦落下去，Safari 不会弹第二次询问，页面也不报错，它只是安静地给你一条没有声音的音轨。后面我把摄像头和通知也一并翻了一遍，发现三项权限走的是同一套逻辑，但入口分散在三个地方。基础路径在 👉 [Telegram网页版中文指南](https://tlgrbt-web.com) 的 Safari 一节里写得很清楚，这篇只补那些"照着做还是不通"的部分。

## 一、三项权限归谁管：先认清有几层

最容易白折腾半小时的地方，是把"浏览器里的开关"当成唯一开关。实际每一项都要过两层：Safari 自己记一次，操作系统再记一次。两层都放行才算通，缺一层，症状一模一样。

| 权限 | Safari 里的位置 | 系统里的位置（Mac） | 系统里的位置（iPhone / iPad） | 被关掉之后长什么样 |
| --- | --- | --- | --- | --- |
| **麦克风** | 设置 → 网站 → 麦克风 | 系统设置 → 隐私与安全性 → 麦克风 | 设置 → Safari → 麦克风 | 通话接通但对方听不到，电平条没有起伏 |
| **摄像头** | 设置 → 网站 → 相机 | 系统设置 → 隐私与安全性 → 摄像头 | 设置 → Safari → 相机 | 画面全黑或一直转圈，偶尔提示"未检测到摄像头" |
| **通知** | 设置 → 网站 → 通知 | 系统设置 → 通知 → Safari | 设置 → 通知 → Safari | 有人 @ 你完全没有动静，只能自己盯屏幕 |

两个版本差异得先说明，不然后面找不着菜单：Safari 15 之前这个面板叫"偏好设置"，Safari 15 起改叫"设置"，位置和项目名称没变；macOS 13 起，原来的"系统偏好设置"改名"系统设置"，隐私那一栏从单独的"隐私"换成"隐私与安全性"。老系统上按旧名字找，新系统上按新名字找，别在错误的菜单里翻。

还有一件事要提前知道：**这些权限是按域名逐个记的**。同一个站点换了访问入口，在 Safari 眼里就是另一个对象，权限得重新给一遍。这也是为什么有人"昨天还好好的，今天又不行了"——他换了入口。

## 二、麦克风：三条路缺一条都没声音

麦克风是三项里最难自查的，因为失败的姿态太安静。按顺序走，别跳步。

1. **先在 Safari 里看一眼记录。**菜单栏 Safari → 设置 → 网站 → 左侧选"麦克风"。右边列表里找到站点，看下拉框是"允许""拒绝"还是"询问"。是"拒绝"，直接改成"允许"。
2. **再去系统层确认 Safari 有没有被勾上。**系统设置 → 隐私与安全性 → 麦克风，列表里找 Safari，前面的勾必须亮着。这一栏如果 Safari 压根不在列表里，说明它从没成功申请过麦克风，先在站点里点一次通话按钮触发申请。
3. **iPhone 上换一条完全不同的路。**Safari 自己的设置面板在 iOS 上没有麦克风入口，得去 设置 → Safari → 麦克风。iOS 15 起这里多了"每次访问前询问"这个选项，选它意味着每次进通话都要点一次允许，图省事就选"允许"。
4. **改完别只刷新，重开标签页。**权限状态的变更不会让已经建立的音频流复活。刷新有时能拿到新权限，拿不到就关掉标签页重新打开，再点通话按钮。
5. **顺手看一眼菜单栏那个橙点。**Mac 屏幕右上角有麦克风使用指示，通话时该亮。不亮说明音频流根本没建立，问题还在权限层，不是对方网络。

顺带一个容易误判的情况：蓝牙耳机连着但没切到通话模式，电平条会有细微起伏却传不出人声。这不是权限问题，把输出设备手动切到"内置麦克风"对比一下就能区分。

## 三、摄像头：黑框比报错更常见

摄像头的失败姿态比麦克风显眼，但报错文案各不相同，值得记住两句：一句是"Safari 浏览器没有使用摄像头的权限"，另一句是"摄像头正被另一个应用使用"。看到前一句去改权限，看到后一句去关掉正在开着的视频会议软件——摄像头是独占设备，Zoom 或会议客户端占着，浏览器就拿不到。

路径和麦克风同构：Safari → 设置 → 网站 → 相机，改站点那一行；系统层在 系统设置 → 隐私与安全性 → 摄像头，勾上 Safari。iPhone 上是 设置 → Safari → 相机。这个面板里还有"屏幕共享"一项，做屏幕演示时被拦，表现是点了共享没反应，原因也在这里。

两个实操细节。MacBook 合盖外接显示器时，内建摄像头不可用，页面会报"未检测到摄像头"，这时候换外接摄像头或者开盖；iPhone 上 Safari 请求相机时，地址栏左侧会出现一个相机小图标，点它能立刻收回授权，比翻设置快得多。

## 四、通知：站点放行了，系统那一关还在

通知被拦最气人——不是不能用，是错过了你不知道自己错过了。它同样两道关，但顺序和媒体权限相反：**系统先允许 Safari 发通知，浏览器再允许这个站点发**。

Mac 上的完整路径是 系统设置 → 通知 → 在应用列表里找到 Safari → 打开"允许通知"，然后把提醒样式设成"持续"或"横幅"。默认的"临时"样式只闪一下就消失，人不在屏幕前等于没有。Safari 侧是 设置 → 网站 → 通知，把站点那一行从"拒绝"改成"允许"。iPhone 上入口在 设置 → 通知 → Safari，Safari 内部没有这一项。

改完还不响，按这三处排查：站内是不是开了免打扰；系统有没有开着专注模式（iPhone 的静音开关也会压掉提示音）；音量是不是被调到了零。这三处都不在浏览器里，但症状和权限被拒完全一样。更细的通知层级和免打扰处理，站上那篇 [纸飞机网页版中文使用指南](https://tlgrbt-web.com) 讲得比我细，可以去对一遍。

## 五、对着症状查，比逐项翻设置快

真出问题时不必三项全查，按症状定位能省一大半时间。站上那节 [Safari 站点权限设置说明](https://tlgrbt-web.com) 用的也是这个思路，从症状倒推层级：

| 你看到的现象 | 八成是哪一项 | 第一刀切哪里 |
| --- | --- | --- |
| 通话接通，对方听不到 | 麦克风 | Safari 设置 → 网站 → 麦克风 |
| 电平条不动，菜单栏无橙点 | 麦克风（系统层） | 系统设置 → 隐私与安全性 → 麦克风 |
| 视频画面全黑，无报错 | 摄像头 | Safari 设置 → 网站 → 相机 |
| 提示"正被另一个应用使用" | 摄像头被独占 | 关掉会议软件后重试 |
| 无任何提示音，错过消息 | 通知（系统层） | 系统设置 → 通知 → Safari |
| 横幅一闪就没 | 通知样式 | 提醒样式改为"持续" |

## 六、改完仍然不生效，通常是这三个原因

第一个是权限记录卡住了。Safari 的站点权限和网站数据存在一起，那条记录本身坏了，下拉框怎么改都弹回原样。办法是 Safari → 设置 → 隐私 → 管理网站数据，搜出这个站点删掉，再重新打开页面，它会当作第一次访问重新询问。

第二个是扩展在中间插了一手。广告拦截、隐私防护、脚本管理类扩展会顺手接管媒体权限请求，站点放行了也被它挡回去。开一个无痕窗口试一次，无痕里正常基本就是扩展的问题。

第三个是只改了浏览器没改系统，或者反过来。这两层没有联动，改一层另一层仍然是拒绝，症状分毫不变——这也是我在开头那通电话里绕的最大一个弯。

现在的固定动作很简单：新设备第一次打开网页版，先花半分钟把麦克风、相机、通知三项在 Safari 和系统里各看一遍，确认没有一项停在"拒绝"；通话前瞄一眼菜单栏的橙点是否亮起。三项对齐之后，剩下的都交给网络和对方设备。这套清单我照着走了小半年，再没出现过"接通了但没人听见我"的尴尬。
